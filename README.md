# Credit Scorecard End-to-End
This repository implements an end-to-end credit risk scorecard, following industry-standard practices used in banks and fintech companies.

The project covers the full lifecycle of credit scoring:

- Exploratory Data Analysis (EDA) focused on credit risk behavior
- Feature engineering using Weight of Evidence (WoE) and Information Value (IV)
- Logistic regression model for probability of default (PD) estimation
- Model evaluation using Gini coefficient and Kolmogorov-Smirnov (KS)
- Stability monitoring using Population Stability Index (PSI)
- Deployment via FastAPI for real-time scoring

The goal is to build a production-ready, interpretable, and regulator-friendly scorecard model.
